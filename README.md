# 🧬 Codoncore

A bioinformatics web dashboard for rapid DNA sequence analysis, 6-frame Open Reading Frame (ORF) detection, and sliding-window GC-content visualization.

🔗 **Live Dashboard:** [Launch Codoncore Web App](https://codoncore-9gb4iwnhzagxxeegkvp92k.streamlit.app)

## ✨ Features
* **Flexible Input:** Upload `.fasta` / `.fa` files or paste raw DNA sequences directly.
* **6-Frame ORF Translation:** Automatically scans all six reading frames and filters candidate proteins based on a customizable minimum amino acid length.
* **GC-Content Profiling:** Interactive sliding-window GC-content plots powered by Plotly.

## 🛠️ Tech Stack
* **Language:** Python
* **Bioinformatics Engine:** BioPython
* **Frontend & Visualization:** Streamlit, Plotly, Pandas
